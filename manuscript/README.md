# Manuscript

`Paper2_Optics_Express_Manuscript.docx` is the current human-edited Optics Express version.

It deliberately retains unresolved placeholders for coauthors, additional affiliations, corresponding-author email, and funding. Do not treat the file as submission-ready until those fields and the release checklist have been completed.

The older automatic manuscript-build scripts are not included because they regenerate a stale draft and contain wording and layout that no longer match the reviewed manuscript. The analysis and figure pipeline is reproducible independently of Word-document authoring.
